# 可访问性、离线和部署说明

- 界面仅用系统中文字体。证书首次生成时才加载约数十KB的 `certificate.woff2`；字库只含固定文案，姓名缺字由系统字体补足，加载失败不阻止下载。字体遵循目录内OFL许可。
- 离线缓存：首次成功联网访问后，等待辅助状态“离线导览已就绪”。应用壳、8点图文、照片、10段音频及字幕在同一版本缓存安装成功后方可离线使用。首次访问即无网、空间不足或禁用SW时无法保证缓存；会有辅助状态说明。离线状态按钮可打开文字点位列表。高德瓦片不缓存，离线地图背景可能空白，不影响文字与音频。
- Cloudflare Pages托管；使用内容摘要作为SW缓存版本，更新时完整安装新版后替换旧缓存；注册时禁用SW脚本HTTP缓存。入口页按目录URL预缓存，避免index.html重定向影响离线导航。修改web资源后必须运行 `python3 tools/build_offline.py` 再发布；已有页面下次重新打开使用新版。不承诺离线时取得服务器尚未访问的新版。
- 键盘：Tab/Shift+Tab在打开的对话框内循环，Escape关闭并返回触发控件；详情时可访问数字人的播放控件。点位、印章和路线链接可用键盘激活；装饰性路线时长不进入焦点序列。播报区提供字幕、状态与证书文本替代。
- 最低声明测试基线：Chrome 61及以上、Safari 12及以上。补充inset、aspect-ratio、min()和flex间距回退；字体API缺失/失败可降级。未取得真实旧版X5、Android7或iOS12设备，不能将现代Chromium测试冒称老引擎验证。低于Chrome55的X5不在支持范围（现有async语法需要相应引擎）。
- 已提高未集章文字、金色完成标记的对比度，资料来源、说明文字和移动字幕提高至0.875rem；系统文字缩放与浏览器手势缩放不受viewport禁止。
- 问答保存本轮题目与答案，刷新或切换标签后继续；完成后“再来一组”创建新一轮，“重置打卡记录”同时清除问答会话。进度仍是当前浏览器/域名本地数据，不提供跨设备备份。
- 媒体播放受限或失败时保留重试按钮，字幕失败给出正文入口提示；暂停、结束、缓冲和后台时停止口型RAF。开场与结语全文可在“关于”折叠栏阅读。真实iOS/微信连续播放策略仍待实机验证。
- 已添加页面描述与标准图首个主机预连接；未裁剪Leaflet或提高瓦片分辨率，以免引入兼容性及额外流量风险。无需登录，未加入账号或外部CDN脚本。
- 正式入口为 https://menglianggu-guide.pages.dev/ ，不依赖临时隧道。未实测中国大陆运营商、真实屏幕阅读器及所有旧手机；外链资料和地图仍依赖其服务可达性，不能保证公网线路。
- 本机常驻CDP浏览器在移除网络字体后出现中文方框，并使用定制的 `/opt/.devin/browser-fonts/fonts.conf`。全新独立Chromium使用同机系统字体可正常显示，证书姓名也已实际检查。因此回归改用独立Chromium，未重启或修改共享浏览器。常驻会话缺字的具体原因（字体缓存、配置或进程版本差异）未完全查明，不将它推广为真实中文手机的缺字结论。

## 重建字体

先为同一Python解释器安装 `python3 -m pip install 'fonttools[woff]'`。`tools/build_offline.py` 默认从 `~/.local/share/fonts/NotoSansCJKsc-Regular.otf` 读取完整OFL字体，仅输出固定文案子集到站点。完整字体不再随站点分发。修改证书固定文案时同步更新该脚本的GLYPHS。
